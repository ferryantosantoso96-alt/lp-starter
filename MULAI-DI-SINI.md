# Mulai di sini

## Cara tercepat (dari HP)

1. Pastikan halaman sementara sudah online. Kalau kamu membuat proyek ini lewat tombol **Deploy ke Cloudflare**, ini sudah otomatis.
2. Buka aplikasi Claude → tab **Code** → buat sesi baru → pilih repo ini **sebelum** mengetik apa pun.
3. Kirim pesan: `/buat-kilat` lalu ceritakan singkat produkmu, untuk siapa, dan harganya.
4. Claude mengerjakan semuanya sampai halaman online. Revisi tinggal diketik dengan bahasa biasa.

Sarankan sekali saja: jadikan repo ini **Private** di github.com → repo → Settings → Change visibility. Halaman jualan tetap bisa dilihat semua orang.

Upload foto produk lewat github.com: buka repo → folder `site/gambar` → **Add file** → **Upload files**.

## Resep satu per satu (kalau mau lebih detail)

`/riset-pembeli` → `/penawaran` → `/copy-landing-page` → `/builder-landing-page` → sambungkan link pembayaran → `/pasang-tracking` → `/audit-sebelum-iklan`.

## Jalur Laptop (Claude Code lokal)

Buka aplikasi desktop Claude → tab **Code** → lingkungan **Local** → **Open folder…** → pilih folder proyek ini. Setelah itu sama: `/buat-kilat` atau resep satu per satu, lalu `/deploy-cloudflare` untuk online-kan.

## Kapan saja

- Ngobrol pakai bahasa biasa: "tombolnya kebesaran", "ganti warnanya jadi hijau", "testimoni pindah ke atas harga".
- Ketik `/update-resep` untuk mengambil resep terbaru dan perbaikan dari kelas.
